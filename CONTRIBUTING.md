# Contributing

Describe the bug and reproduction before making a focused change. Run `npm run typecheck` and `npm test`; report any omitted-asset limitations separately. Keep interface changes consistent across all six locale files. Preserve platform-specific native integrations rather than replacing one platform with another.

Do not commit game media, account configuration, signing materials, personal logs or credentials. Use example product/app identifiers. Native behavior requires separate platform setup and device verification; passing TypeScript tests does not establish it.

Contributions to authored code in this repository are submitted under GPL-3.0-only. Preserve third-party notices and identify third-party code before adding it. No permission to use the original game branding is implied.
